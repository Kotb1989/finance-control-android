# Finance Control MVP – إدارة العهد وسندات الصرف

## ما يتضمنه الإصدار
- واجهة عربية RTL متجاوبة.
- لوحة تحكم بمؤشرات تجريبية.
- سجل العهد وإضافة عهدة مؤقتة أو مستديمة.
- سجل سندات الصرف وإضافة سند نقدي أو تحويل بنكي.
- شاشة تسجيل تسوية عهدة مبسطة.
- شاشة تهيئة الربط المحاسبي الخارجي.
- تصدير سجلات العهد والسندات بصيغة CSV.
- مخطط PostgreSQL أولي متعدد الشركات.

## تشغيل الواجهة
1. فك ضغط الملف.
2. افتح `index.html` مباشرة في متصفح حديث.
3. لا يحتاج العرض الأولي إلى تثبيت أو خادم.

## مهم قبل التشغيل الفعلي
هذه نسخة واجهات MVP للعرض وتجربة تدفق العمل. البيانات محفوظة في ذاكرة الصفحة فقط وتعود إلى بيانات العرض عند إعادة التحميل. لا تتصل الواجهة بقاعدة البيانات ولا تنفذ موافقات حقيقية أو قيودًا محاسبية فعلية.

## قاعدة البيانات
- نفّذ `database/schema.sql` على PostgreSQL بعد مراجعة المخطط.
- أنشئ مستخدمي النظام والأدوار وسياسات الاعتماد.
- أضف طبقة Backend/API للتحقق من الصلاحيات وتنفيذ المعاملات.
- اربط التخزين بمخزن ملفات خاص وآمن للمرفقات.

## التكامل المحاسبي الخارجي
يلزم تحديد اسم النظام المحاسبي ومواصفات API (المصادقة، دليل الحسابات، مراكز التكلفة، نقاط إنشاء القيود، الاستعلام عن حالة الترحيل). يستخدم التصميم جدول `integration_outbox` لإرسال أحداث موثوقة قابلة لإعادة المحاولة دون تكرار.

## ضوابط مطلوبة قبل الإنتاج
- مصادقة آمنة، MFA عند الحاجة، وصلاحيات على مستوى الشركة.
- تحقق خادمي من حدود الاعتماد ومنع اعتماد المنشئ لطلبه.
- معاملات قاعدة بيانات ذرية وقفل الفترات المالية.
- عدم تعديل المستندات المرحلة؛ التصحيح بقيد/مستند عكسي.
- سجل تدقيق غير قابل للتعديل من واجهة المستخدم.
- تشفير الأسرار والنسخ الاحتياطي واختبار الاستعادة.
- مراجعة معالجة ضريبة القيمة المضافة وفق حالة كل فاتورة ومتطلبات هيئة الزكاة والضريبة والجمارك.

## هيكل الملفات
- `index.html`: نقطة تشغيل الواجهة.
- `styles.css`: التنسيق.
- `app.js`: منطق واجهة العرض التجريبية.
- `database/schema.sql`: مخطط قاعدة البيانات.
